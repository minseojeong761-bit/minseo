# 오늘 뭐 먹지? (맞춤형 식단 추천 웹사이트)

개인의 음식 취향, 하루 식비 예산, 냉장고 보유 식재료, 원하는 식사 유형을 분석해 맞춤형 메뉴 3가지를 바로 추천해 주는 한국어 웹 애플리케이션입니다. 별도의 외부 API 키 설정 없이 바로 실행할 수 있습니다.

## 주요 기능
- **음식 취향 선택**: 한식, 양식, 중식, 일식 (복수 선택 가능)
- **식사 유형 선택**: 건강식, 간편식, 든든한 식사
- **하루 식비 예산 설정**: 직접 입력, 빠른 선택 버튼, 슬라이더 지원 (예산 초과 방지)
- **보유 식재료 관리**: 태그 입력/삭제 및 자주 쓰는 재료 빠른 추가 (동의어 포함 자동 매칭)
- **맞춤형 추천 결과**:
  - 맞춤형 메뉴 3가지 + 추천 이유
  - 보유/추가 구매 구분된 식재료 및 정확한 분량
  - 구체적인 단계별 조리 순서
  - 예상 조리 시간 및 예상 식재료 비용 (예산 대비 게이지 표시)

## 실행 방법
1. `start.bat`을 더블클릭하거나 터미널에서 아래 명령어를 실행합니다.
   ```cmd
   npm.cmd start
   ```
2. 브라우저에서 [http://localhost:3000](http://localhost:3000) 으로 접속합니다.
